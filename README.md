# Projeto Feira Solidária - Capacita Equipe 2

![Badge de Status do Projeto - Ex: Em Desenvolvimento]
Este é o repositório do projeto "Feira Solidária", desenvolvido pela Equipe 2 no módulo intermediário do Capacita C-Jovem. Nosso objetivo é criar uma plataforma web para conectar doadores e pessoas em situação de vulnerabilidade social, facilitando a doação e o acesso à alimentos, produtos de higiene e de limpeza de forma digna e com burocracias acessíveis e pouco exigentes, com o objetivo de contribuir para com a sociedade e visando democratizar o acesso a produtos não perecíveis e à segurança alimentar para muitas famílias carentes na atualidade.

---

## 🚀 Visão Geral do Projeto

A "Feira Solidária" visa combater a insegurança alimentar e a carência de itens essenciais através de um sistema intuitivo e simples de usar. Os usuários podem se cadastrar como doadores, listando itens disponíveis dos quais não precisam mais, que podem ser necessários para outras pessoas, ou como receptores, que procuram produtos para satisfazerem suas respectivas necessidades básicas biológicas( alimentação e higiene pessoal), buscando o que precisam na respectiva região de cada indivíduo cadastrado na plataforma web desenvolvida. A plataforma é uma ponte entre a solidariedade e a necessidade, incentivando a tecnologia a serviço do bem social.

## ⚙ Estrutura e Tecnologias

O frontend da aplicação foi desenvolvido com foco em organização, escalabilidade, manutenibilidade, eficiência e acessibilidade.

* Ferramenta de Build: Vite - Escolhido pela sua velocidade, simplicidade e suporte moderno a ESModules e Hot Module Replacement (HMR).
* Framework Frontend: React.js - Para a construção da interface de usuário baseada em componentes.
* Gerenciamento de Rotas: React Router DOM - Para a navegação declarativa entre as diferentes páginas da aplicação.
* Estrutura de Pastas: src/components/ (para componentes reutilizáveis) e src/pages/ (para componentes de páginas).

---

## 🗺 Rotas Implementadas (Frontend)

As seguintes rotas estão configuradas e utilizam um layout base comum:

* / - Página Inicial
* /login - Página de Login
* /cadastro - Página de Cadastro
* /perfil - Página de Perfil do Usuário
* /item/:id - Página de Detalhes de um Item específico
